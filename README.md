# 📻 AeroPTT — Защищенная Тактическая Рация (Push-to-Talk)

Кроссплатформенное приложение-рация (Android, iOS, Windows, Mac, Linux) для **мгновенной голосовой связи** по локальной сети, Wi-Fi или точке доступа (Hotspot) **без интернета, без регистрации и без звонков**.

---

## ⚡ Как это работает

1. **Мгновенный звук (Zero-Ring PTT)**: Вы зажимаете кнопку «Нажми и говори» (или клавишу `ПРОБЕЛ`) — и ваш голос сразу же воспроизводится из динамика собеседника. Никаких экранов «Входящий вызов» или кнопок «Ответить».
2. **Сквозное шифрование (AES-256-GCM)**: Аудиопоток шифруется военным стандартом. Если злоумышленник попытается перехватить трафик в Wi-Fi сети, он услышит только белый шум.
3. **Автономность 100%**: Работает в поле, в горах, в автомобилях, в зданиях. Достаточно включить точку доступа на одном смартфоне, а со второго подключиться к ней.
4. **Тактические радиоэффекты**:
   - Щелчок механической тангенты (Keying Click)
   - Шумоподавитель эфира (Squelch)
   - Сигнал окончания передачи (Roger Beep)
   - Фильтр полосы частот рации (300 Гц – 3.4 кГц)

---

## 🚀 Быстрый запуск

### Вариант 1: Запуск на компьютере (Сервер-шлюз)
1. Дважды кликните по файлу **`start.bat`** (или выполните `python server.py` в консоли).
2. В консоли отобразится ваш локальный адрес (например, `http://192.168.1.45:8080`).
3. Откройте эту ссылку в браузере или нажмите кнопку **`📱 QR`** в интерфейсе и отсканируйте камерой смартфона.

### Вариант 2: Установка на смартфон (как нативное приложение PWA)
- **На Android (Chrome / Яндекс / Samsung Browser)**: откройте адрес -> нажмите меню (три точки) -> **«Установить приложение»** или **«Добавить на главный экран»**.
- **На iPhone (Safari)**: откройте адрес -> нажмите кнопку «Поделиться» -> **«На экран "Домой"»**.

## 🎛️ Элементы управления
- **Кнопка PTT (Красная)**: Зажать пальцем или нажать `ПРОБЕЛ` на клавиатуре для передачи.
- **CH- / CH+**: Переключение между 16 тактическими каналами (PMR446: 446.00625 – 446.19375 МГц).
- **🔒 KEY**: Настройка секретного PIN-кода шифрования канала (по умолчанию `7788`).
- **📱 QR**: Показать QR-код для быстрого подключения напарника.
- **⚙️ CFG**: Смена позывного (Callsign), цвета подсветки ЖК-дисплея (янтарь, зеленый, синий) и настройка звуковых спецэффектов.
